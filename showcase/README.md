# $bog_vmap_showcase

Сквозной тест редактора: в собранном `app/-/index.html` по CDP собирается настоящее приложение из деталей пака и выгружается кнопкой «Скачать». Механика браузера — пак `probe`.

Приложение — «Ипотека», корневой класс набирается в поле имени корня, модуль выгрузки `bog/mortgage`. Два артборда. `Loan`: сумма, ставка и срок полями `$mol_number`; калькуляторы ставки в месяц и числа месяцев; платёж и переплата абзацами из тела корня; график остатка долга; ячейка кода с текущим годом и калькулятор года последнего платежа; ссылка на сравнение. `Compare`: та же сумма двусторонним проводом, другая ставка, свой график, итог сравнения и ссылка назад. Страницы переключает роутер выгрузки по `page` в адресе.

Жестом мыши и клавиатуры, как пользователь: имя корня, первый артборд кнопкой «Артборд» и тягой, первая деталь тягой с полки, провод `Rate.value → Monthly.left` и двусторонний `Years.value ⇄ Months.left` с Shift, выгрузка кликом по «Скачать». Остальное — теми же портами оболочки, что зовёт интерфейс: `part_drop`, `board_draw`, `link_add`, `node_source`, `node_title`, `code_js`, `code_css`.

Провод `Amount.value ⇄ Amount_2.value` кладётся портом: жестом его не проложить. У `$mol_number` двадцать два своих порта, точка `value` двадцатая, на 273 px ниже верха узла высотой 40, а колонка цели раскрыта, только пока указатель над узлом.

Начальные значения полей — привязкой к свойству корня, `value? <=> amount? 6000000`. Форма `value? 6000000`, которую пишет инспектор, компилируется в `(next) => 6000000`, и поле перестаёт принимать ввод.

Проверки: порядок деталей на артбордах, провода в документе, отрисованный документ в песочном кадре сцены (калькуляторы, платёж, сумма по двустороннему проводу, точки графиков), архив открывается `unzip` и байт в байт равен выгрузке оболочки, в нём роутер, хуки тела и все провода. Отчёт — `-/showcase.log`, архив — `-/mortgage.zip`, распакованный модуль — `-/bog/mortgage/`.

Вторая проверка, `$bog_vmap_showcase_site`, открывает уже собранную выгрузку: платёж на первой странице, набор новой суммы, переход по ссылке, та же сумма на второй странице, правка там и возврат. В CI она идёт отдельным шагом после сборки выгрузки, архив и модуль уходят артефактом `showcase-app`.

```bash
npx mam bog/vmap/app
npx mam bog/vmap/scene
npx mam bog/vmap/part
npx mam bog/vmap/showcase
cp -R bog/vmap/showcase/-/bog/mortgage bog/mortgage
npx mam bog/mortgage
node -e 'require( process.cwd() + "/bog/vmap/showcase/-/node.js" ).$bog_vmap_showcase_site().then( ()=> process.exit( 0 ), ()=> process.exit( 1 ) )'
```

Модуль соседний, а не подпапка `probe/`: имя подпапки затащило бы в бандл тест пробы вёрстки. По имени его никто не зовёт. Без Chrome тест отдаёт пропуск и остаётся зелёным.
